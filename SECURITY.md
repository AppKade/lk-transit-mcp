# Security

Report vulnerabilities through GitHub private vulnerability reporting when available, or **contact@appkade.lk**. Never include real passenger records, coordinates, credentials or private feeds in public issues.

The executable requires `--demo`, exposes five read-only MCP tools and a coverage resource over local stdio, and loads only a bundled synthetic fixture. It has no network adapter, file tool, database, account, payment action or remote listener. Coordinates stay in memory; the AI host may still retain arguments and results in conversation history.

Strict schemas bound coordinates, radius, text, collections and result counts. Activation checks IDs and references before replacing state. Upstream strings must remain data rather than host instructions. Tool results, including query failures, carry synthetic provenance and a travel-use warning.

Before live ingestion, review source rights and privacy; constrain fetch protocols, redirects, hosts, timeouts and sizes; safely unpack bounded archives; quarantine orphan references; preserve observation timestamps; verify stale states and last known-good fallback. Never log exact user coordinates.

Remote transport requires an Origin/auth/rate-limit/threat review and protocol tests. Do not expose this demo through an HTTP proxy as a public live service.
